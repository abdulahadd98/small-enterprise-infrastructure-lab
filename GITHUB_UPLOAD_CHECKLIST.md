# GitHub Upload Checklist

Before pushing the repository:

- [ ] Review `README.md` and replace/add your own name if desired.
- [ ] Confirm no passwords, private keys, tickets, or credentials exist.
- [ ] Confirm screenshots do not reveal anything you consider private.
- [ ] Do not upload VM disks, ISO files, or snapshots.
- [ ] Keep `.gitignore` in the repository root.
- [ ] Use a repository name such as `small-enterprise-infrastructure-lab`.
- [ ] Add a short GitHub description: `Windows Server 2019 AD DS, DNS, GPO, file/print services, and Linux integration lab.`
- [ ] Suggested topics: `active-directory`, `windows-server`, `group-policy`, `dns`, `linux`, `samba`, `winbind`, `system-administration`, `homelab`.
- [ ] Pin the repository on your GitHub profile after publishing.

Suggested first commit message:

```text
Initial release: enterprise infrastructure lab documentation and configs
```
